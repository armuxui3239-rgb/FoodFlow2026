## ลำดับวินัยต่อหนึ่งงาน (Definition of Done)

1. **สรุปก่อนลงมือ** — ทำอะไร เกี่ยวกับอะไร ไฟล์ไหน (ตามคำสั่งเจ้าของ)
2. **ทำ** — เขียนโค้ดตามขอบเขตที่ประกาศไว้เท่านั้น
3. **ตรวจโค้ด** — `npx tsc --noEmit` (ไฟล์ที่แตะ = 0 error) + `npm run lint` (0 error)
4. **ตรวจ build** — `next build` ผ่าน (สำหรับงานใหญ่/ก่อน release)
5. **ตรวจฟังก์ชัน** — รัน `node --env-file=.env scripts/qa-smoke.mjs` (ชุดทดสอบวงจรธุรกิจอัตโนมัติ — ครอบ 4 บทบาท)
6. **ตรวจข้อมูล** — ถ้าแตะ DB: นับ count จริง + เงื่อนไขธุรกิจ (สตางค์/orphan/history)
7. **รายงานจริง** — ผ่าน/ไม่ผ่าน/ข้อจำกัด + สิ่งที่รอเจ้าของ — ห้ามเคลมเกินหลักฐาน
