# นโยบายความเป็นส่วนตัว (Privacy Policy) — ฟู๊ด ธันเดอร์

> **ฉบับร่างสำหรับเจ้าของโปรเจกต์ตรวจ/อนุมัติ** (v4 ข้อ 13.8) — เมื่ออนุมัติแล้วให้นำไปแสดงในหน้า /help และขั้นตอนสมัครสมาชิก
> จัดทำ 2026-11-14 · อ้างอิงหลัก PDPA พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562

## 1. ข้อมูลที่เราเก็บ

| ข้อมูล | เพื่ออะไร | ฐานทางกฎหมาย |
|---|---|---|
| เบอร์โทรศัพท์ (ตัวระบุหลัก) | ล็อกอิน/ยืนยันตัวตน/ติดต่อจัดส่ง | สัญญา (จำเป็นต่อการให้บริการ) |
| อีเมล, ชื่อ-นามสกุล | ยืนยันตัวตน ติดต่อ ใบเสร็จ | สัญญา |
| ที่อยู่จัดส่ง + พิกัด | จัดส่งอาหารถึงคุณ | สัญญา |
| วันเกิด (ไม่บังคับ) | ตรวจ PIN ไม่ให้ตรงวันเกิด (ความปลอดภัย) | ผลประโยชน์ที่คาดหวัง |
| ประวัติคำสั่งซื้อ/การชำระเงิน/กระเป๋าเงิน | บันทึกธุรกรรม ภาษี การคืนเงิน | สัญญา + ภาระผูกพันทางกฎหมาย |
| รีวิว/ทิป/แชท | คุณภาพบริการ บันทึกข้อพิพาท | สัญญา |
| สลิปโอนเงิน (รูปภาพ) | ให้แอดมินตรวจยอดเติมเงิน | สัญญา — เก็บ bucket ปิดสาธารณะ |

**เราไม่เก็บ:** ข้อมูลบัตรประชาชน · ภาพใบหน้า (ไบโอเมตริกใช้ระบบปฏิบัติการเท่านั้น ไม่มีการอัปโหลด) · ข้อมูลจากผู้ให้บริการภายนอก (ระบบจบในระบบ — ดู [third-party-replacement.md](third-party-replacement.md))

## 2. ข้อมูลที่เก็บไม่ออกจากระบบ

- เงินทุกธุรกรรมเป็นสตางค์จำนวนเต็ม คำนวณในระบบ — ไม่มีผู้ให้บริการชำระเงินภายนอก
- รหัสยืนยัน OTP แสดง**ในแอป**เท่านั้น ไม่มีการส่ง SMS ออกภายนอก
- รหัสผ่าน/PIN/OTP เก็บเป็น **hash (bcrypt)** เท่านั้น — ไม่มีใครอ่านย้อนได้ รวมทั้งผู้ดูแลระบบ

## 3. สิทธิ์ของท่าน (ตาม PDPA)

1. **สิทธิ์เข้าถึง** — ดูข้อมูลของตนเองได้ที่หน้าโปรไฟล์/ประวัติ
2. **สิทธิ์แก้ไข** — แก้ชื่อ/อีเมล/ที่อยู่ได้ในแอป
3. **สิทธิ์ลบ (Right to Erasure)** — ปุ่ม "ลบบัญชี" ที่ หน้า ความปลอดภัย → ระบบจะ **ปิดบัญชี + ลบข้อมูลส่วนบุคคลทันที** (ชื่อ→"บัญชีที่ถูกลบ", อีเมล/เบอร์→ค่าอสัญฐาน, ที่อยู่/ร้านโปรด/PIN ถูกลบ) — คงบันทึกธุรกรรมแบบไม่ระบุตัวตนไว้ตามภาระกฎหมายภาษี/ข้อพิพาท
4. **สิทธิ์คัดค้าน/ถอนความยินยอม** — ปิดการแจ้งเตือนได้ที่ ตั้งค่า → การแจ้งเตือน
5. **สิทธิ์ร้องเรียน** — ติดต่อฝ่ายบริการลูกค้าผ่านช่องทางในหน้า /help

## 4. การรักษาความปลอดภัย

- เข้ารหัสขนส่งทั้งหมด (HTTPS/TLS) · คุกกี้ session แบบ HttpOnly + Signed (HMAC) + Secure ใน production
- RLS เปิดทุกตาราง (ปิดการเข้าถึงตรงจากภายนอก) — แอปสื่อสารผ่าน backend เท่านั้น
- Rate limit ทุก endpoint · ล็อกบัญชีอัตโนมัติเมื่อ PIN/รหัสผ่านผิดซ้ำ
- สลิปการโอนเก็บใน Storage bucket แบบ private อ่านเฉพาะแอดมินผ่านระบบ

## 5. การเก็บรักษา (Retention)

- ข้อมูลบัญชี: เก็บระหว่างใช้บริการ — ลบตามข้อ 3.3 เมื่อท่านขอ
- บันทึกธุรกรรม (หลังลบบัญชี): เก็บแบบไม่ระบุตัวตนเพื่อภาระกฎหมาย
- บันทึก audit ของแอดมิน: เก็บเพื่อการตรวจสอบย้อนหลัง

## 6. ผู้ควบคุมข้อมูลส่วนบุคคล

# ข้อกำหนดการใช้งาน (Terms of Service — ย่อ)

1. บัญชี = ส่วนบุคคล ห้ามโอน/แบ่งปัน — รับผิดชอบการรักษา PIN ของตนเอง
2. การสั่งซื้อถือสมบูรณ์เมื่อร้านตอบรับ; ยกเลิกได้ก่อนร้านตอบรับเท่านั้น (เหตุผลตามระบบ)
3. การเติมเงินใช้พร้อมเพย์ + ผู้ดูแลตรวจสลิป — โอนเฉพาะ QR ที่ระบบสร้างให้ในคำขอนั้น ๆ
4. ห้ามใช้ระบบเพื่อการฉ้อโกง/ทดลองชำระปลอม — บัญชีจะถูกระงับ (is_active = false)
5. รีวิวต้องเป็นจริงตามประสบการณ์ — ผิดจริงจังถึงขั้นระงับบัญชี
6. ระบบอาจระงับบัญชีที่ผิดข้อกำหนดโดยแจ้งเหตุผลให้ทราบ
