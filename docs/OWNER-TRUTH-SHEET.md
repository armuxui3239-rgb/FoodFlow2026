# แผ่นความจริงฉบับเจ้าของ (Owner Truth Sheet)

## กติกาการทำงานที่ตกลงกัน (กติกาที่ 2)

1. แก้โค้ดในเครื่องได้ · **push ขึ้นเว็บจริงต้องถามเจ้าของยืนยันทุกครั้ง**
2. เอกสารมาก่อนโค้ดเสมอ — งานใหม่ต้องมีบันทึกในเอกสารตามไปด้วย
3. ทุกข้อสรุปต้องอ้างไฟล์/บรรทัด ห้ามสรุปลอย

**การ์ดเหลืองบนหน้ายืนยัน (ที่ดูเหมือน "ข้อความเดโม")**:
- ข้อความจริงบนจอ: "รหัสยืนยันของคุณ: XXXXXX / ระบบลงรหัสในช่องให้อัตโนมัติแล้ว — ตรวจทานแล้วกดยืนยันได้เลย (ไม่มีการส่ง SMS)"
- ที่มา: ออกแบบไว้ตั้งแต่ 0.7.1 ตามนโยบาย "ข้อความตรงความจริงทุกจุด" (เลิกอ้างว่าส่ง SMS)

## ของค้างจริง (ทั้งหมดรอการตัดสินใจ/คำสั่งเจ้าของ — ไม่ใช่รอซ่อม)

1. **แท็บที่ 5 "ข้อความ"** — โค้ดแก้แล้วในเครื่อง (ยังไม่ push) รอ: ทิ้ง / ดูพรีวิว / ขึ้นเว็บ
2. **การ์ดเหลืองหน้า OTP** — ปล่อยตามดีไซน์ หรือแก้ข้อความ/ซ่อน ตามสั่ง
3. **Dark mode** — รอคำสั่ง
4. **i18n สองภาษา** — รอคำสั่ง
5. **PDPA เปิดนโยบายจริง** — เจ้าของพิมพ์ "PDPA อนุมัติ" เมื่อพร้อม
6. **Key rotation 3 กุญแจ** — แนะนำทำก่อนเปิดใช้จริง (คู่มือ docs/KEY-ROTATION.md)
7. **ลบโปรเจกต์เปล่า food-thunder บน Vercel** — เจ้าของกดยืนยันผ่านลิงก์ที่ส่งแล้ว
