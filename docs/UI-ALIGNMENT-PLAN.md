## 1. มาตรฐานดีไซน์ของเจ้าของ (สกัดจากหน้าลูกค้า — หลักฐานย่อ)

1. **พาเลตต์ตายตัว:** `#FFC400` แบรนด์ (พื้นปุ่ม/ไฮไลต์, ตัวอักษรเหลือง**เฉพาะบนพื้นดำ**, ดาว), `#FFF4CC` พื้นอ่อน/สีโฮเวอร์, `#0a0a0a` ดำ (ตัวอักษรหลัก/การ์ดดำ), การ์ดขาว, `neutral-50/100` ช่องกรอก+โครงร่างโหลด, `neutral-400` ตัวรอง/`neutral-300` ไอคอนปิด; แดง = ข้อผิดพลาด (พื้น `bg-red-50` + ตัว `text-red-600/500`), เขียวเป็น**ข้อความเท่านั้น** (`text-emerald-600`) — ห้ามพื้นสีเขียว/น้ำเงิน/ฟ้า/เทา slate/gray
2. **เส้นขอบ:** ทุกอย่าง `border border-line` (`#f1f1f4`) — ตัวคั่นรายการเป็น `border-t border-line`
3. **ทรง:** การ์ด `rounded-3xl`, กล่องชั้นใน/ช่องกรอก `rounded-2xl`, ไอคอน `rounded-xl`, ชิป/ปุ่ม/ป้าย `rounded-full` — **ห้าม rounded-lg/md**; เงาบาง (`shadow-sm`, hover `shadow-md`)
4. **ปุ่มหลัก:** `.btn-brand` + สูง h-11/h-12 (h-14 ปุ่มเด่น), `text-sm`; ปุ่มรอง = ขาวขอบ line `hover:bg-neutral-50` หรือ `hover:bg-[#FFF4CC]`; ปุ่มเด่นรอง = `bg-black text-[#FFC400] hover:bg-black/90`; ปุ่มลบ = ขอบแดง
5. **ชิป/แท็บ:** แท็บเลือก = แทร็ก `rounded-full bg-neutral-100 p-1` + ชิปเลือก `bg-black text-[#FFC400]` / ว่าง `bg-white text-neutral-600`; ป้ายสถานะ = `rounded-full px-2 py-0.5 text-[11px] font-bold`
6. **การ์ด/แถวรายการ:** `rounded-3xl border border-line bg-white` (+`p-4`/`shadow-sm`/`overflow-hidden`); แถว `flex items-center gap-3 px-4 py-3` คั่น `border-t border-line`; รูปอยู่ใน `rounded-2xl bg-neutral-100`
7. **ช่องกรอก:** ช่องค้นหา = `h-12 rounded-full bg-neutral-100 px-4`; ฟอร์ม = `rounded-2xl border border-line bg-neutral-50 px-4 py-3.5 outline-none` + โฟกัสเหลือง (`focus-within:border-brand` / `focus:border-[#FFC400]`) — **ห้ามพื้นขาว/ห้ามโฟกัสสีดำ**
8. **ตัวอักษร:** ฟอนต์ Prompt; ขนาด `[10-11px]` จิ๋ว → `xs` เมตา → `sm` เนื้อหา → `base/lg` หัวข้อ → `xl/2xl` ตัวเลขเด่น; น้ำหนัก `font-bold` เป็นหลัก (219 จุด); ตัดคำไทยด้วย `.truncate-1/2`
9. **เลย์เอาต์:** คอลัมน์เดียว `mx-auto max-w-5xl px-4` (space-y-4/5, py-5) — **ห้าม max-w-6xl**; แถบหัว sticky `h-14 border-b border-line bg-white/95 backdrop-blur`; หน้าย่อย = ปุ่มย้อนกลม + หัวข้อ `text-lg font-bold` + นับจำนวน `text-xs text-neutral-400`; เนื้อหาเว้นล่าง `pb-28+`; bottom sheet = `rounded-t-3xl`
10. **สถานะ:** โหลด = โครงร่าง `animate-pulse rounded-3xl bg-neutral-100` (ห้ามหมุน spinner อย่างเดียว); ว่าง = วงกลมไอคอน `bg-neutral-100` + หัวข้อ `text-lg font-bold` + คำอธิบาย `text-sm text-neutral-400` + ปุ่ม btn-brand; ผิดพลาด = `rounded-2xl bg-red-50 px-4 py-3 text-sm text-red-600`; dialog = Radix ปรับ `rounded-3xl`; สวิตช์ = เปิด `bg-black` ปิด `bg-neutral-200`

**ข้อสังเกตภายในหน้าลูกค้า 11 จุด (ไม่แตะ หากเจ้าของไม่สั่ง)** — เช่น ใช้คำศัพท์สี 2 ระบบ (token vs raw), ปุ่มย้อนกลับ 2 แบบ, โฟกัสช่องกรอก 3 สไตล์, ขนาดหัวข้อเอียงเล็กน้อย, `hover:bg-[#ffd34d]` จุดเดียว — ถ้าต้องการให้จัดระเบียบตามมาตรฐานข้อ 1–10 ให้แจ้งเป็นงานเพิ่ม
